# freshGram Android — документация

> English README: [`README.md`](../README.md)

Неофициальный клиент Telegram для Android, переносящий на базу **Nekogram**
полезные функции **freshGram Desktop**, **AyuGram** и **Materialgram**.
Не связан с Telegram, Nekogram и командой freshGram Desktop и ими не
поддерживается.

## Что это вообще

freshGram Desktop — форк Telegram Desktop, добавляющий приватность и удобство
(режим призрака, история сообщений, анти-удаление, режим стримера, оформление).
Этот проект переносит ту же идею на Android, сохраняя зелёный брендинг freshGram
и добавляя отдельные функции из экосистем AyuGram и Materialgram.

## Версии full и lite

Каждый релиз содержит два варианта отдельными APK:

| Вариант | Описание |
|---|---|
| **full** | Всё, включая приватные функции. Для личного использования. |
| **lite** | Приватные функции отключены, собрана с `-PfreshgramLite=true`, рассчитана на соблюдение политики Google Play. |

Обе версии используют **один** пакет (`app.freshgram.android`), поэтому
устанавливать нужно **только одну**, и в Google Play можно загрузить лишь одну.

Функции, которые в lite отключены: анти-удаление, режим призрака, «оставлять
удалённые чаты», режим стримера, история правок, «сохранять удалённые
сообщения», скрытие спонсорских сообщений и выбор без ограничений (>100).

Всё остальное одинаково: зелёная тема и брендинг, выбор иконки приложения,
порядок вкладок, шрифты, смена языка и стартовый экран.

## Скачивание

APK прикрепляются к [GitHub Releases](../../releases):

```
freshGram-<версия>-<код>-full-universal.apk      # все ABI
freshGram-<версия>-<код>-full-arm64-v8a.apk      # современные телефоны
freshGram-<версия>-<код>-full-armeabi-v7a.apk    # старые 32-битные телефоны
freshGram-<версия>-<код>-lite-universal.apk
freshGram-<версия>-<код>-lite-arm64-v8a.apk
freshGram-<версия>-<код>-lite-armeabi-v7a.apk
```

Установка:

```bash
adb install -r freshGram-13.1.5-7241-full-universal.apk
```

## Автообновление с GitHub

freshGram сам проверяет свои релизы на GitHub — Play Store и ручное скачивание
APK не нужны:

- приложение запрашивает
  `https://api.github.com/repos/Greznish297477/freshgram-android/releases/latest`;
- сравнивает версию последнего релиза с установленной и выбирает APK под ABI
  устройства и вариант сборки (**full** или **lite**);
- если есть новая версия, показывает диалог с описанием изменений; кнопка
  **«Скачать»** загружает APK прямо в приложении и передаёт его системному
  установщику (разрешение `REQUEST_INSTALL_PACKAGES` уже объявлено);
- ручная проверка — **Настройки freshGram → Проверить обновление** (также есть
  в **Настройки freshGram → Экспериментальные → Проверить обновление**);
  автоматическая выполняется не чаще раза в сутки.

> Если переименовать репозиторий или перенести проект к другому владельцу,
> поменяйте `REPO_OWNER` / `REPO_NAME` в
> `TMessagesProj/src/main/java/tw/nekomimi/nekogram/helpers/FreshgramUpdater.java`.
> Обновления работают только для релизов, в которых есть файлы
> `freshGram-*-<вариант>-<abi>.apk`; workflow релиза создаёт их автоматически.

## Локальные закрепы (больше 5 закреплённых чатов)

Telegram ограничивает закрепы на сервере (5 на папку для бесплатных аккаунтов).
freshGram добавляет *локальные закрепы* — закрепы, которые существуют только на
этом устройстве и никуда не отправляются:

- обычное «**Закрепить**» работает как обычно: когда серверный лимит исчерпан,
  freshGram оставляет лишний закреп только на устройстве вместо ошибки
  «достигнут лимит». Визуально он не отличается от обычного, в меню пишется
  «**Открепить**»;
- можно сразу закрепить локально через **⋮ → Закрепить локально** (или выделить
  несколько чатов → **⋮ → Закрепить локально**).
- локально закреплённый чат получает такую же иконку булавки и стоит в блоке
  закрепов, сразу после настоящих серверных закрепов. Лимита на количество нет;
- список хранится в настройках `nekoconfig` (ключ `localPins`), порядок — по
  времени добавления. Он не синхронизируется, не виден на других устройствах и в
  других клиентах Telegram;
- открепить так же: **⋮ → Открепить локально**.

Это не обман Premium и не меняет состояние на сервере, поэтому не может привести
к ограничению или блокировке аккаунта. Обычные закрепы (которые синхронизируются
между устройствами) по-прежнему ограничены сервером.

## Сборка

### Требования

- JDK 25
- Android SDK (build-tools, NDK, CMake — как в CI)
- `local.properties` с API-ключами и настройками подписи

### Локально

```bash
# full + lite, результат в ./dist
./build-versions.sh
./build-versions.sh full
./build-versions.sh lite
```

Или напрямую Gradle:

```bash
./gradlew :TMessagesProj_App:assembleRelease
```

### CI

Workflow [`.github/workflows/release-full-lite.yml`](../.github/workflows/release-full-lite.yml)
собирает оба варианта и публикует GitHub Release при пуше тега `v*`.
Список нужных секретов и шаги — в [`PUBLISH.md`](PUBLISH.md).

### Про подпись

Нативная проверка анти-тампера в `TMessagesProj/jni/colorado/colorado.h` привязана
к конкретному имени пакета и сертификату подписи. Если сменить ключ подписи,
константы **нужно** пересчитать, иначе приложение будет завершаться (`SIGKILL`)
при старте. Debug-ключ приводит к тому же результату.
