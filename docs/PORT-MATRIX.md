## План волн (по возрастанию сложности)

1. **Мелкое и безопасное** (сделано/сейчас): история правок, лимит выбора, порядок вкладок drag, зелёная аватарка Telegram (777000), брендинг.
2. **Простые фичи AyuGram**: показать/копировать ID, скрыть кнопку пересылки, спонсорские сообщения, «удалить за период».
3. **Оформление Materialgram**: Material-иконки, скругления/без хвостов, звуки.
4. **Среднее**: peek last seen, множественные упоминания, кнопки админ-меню.
5. **Крупное**: Vault/зашифрованные чаты, плагины, история удалённых с версиями.

## Важно
- Полный перенос **всех** функций AyuGram + Materialgram за один заход невозможен: это разные платформы (Android vs Qt Desktop) и десятки тысяч строк. Работаем волнами с проверкой на устройстве.
- Всё, что помечено 🚫, либо Desktop-only, либо требует серверных прав Telegram и не может быть включено клиентом.
